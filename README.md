# Сайт МАОУ СОШ №22 им. Д. М. Карбышева

Чистый HTML + CSS + JavaScript, без сборки и фреймворков.

## Структура

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `journal.html` | Электронный журнал |
| `svedeniya.html` | Сведения об образовательной организации |
| `about.html` | О школе |
| `staff.html` | Педагогический состав |
| `schedule.html` | Расписание (уроки, звонки, кружки, каникулы) |
| `services.html` | Услуги и сервисы |
| `useful.html` | Полезная информация |
| `news.html` | Новости |
| `events.html` | Мероприятия |
| `contacts.html` | Контакты |
| `funcgram.html` | Функциональная грамотность |
| `quality.html` | Оценка качества образования |
| `css/style.css` | Все стили (цвета — в начале файла, `:root`) |
| `js/data.js` | **Все данные: новости, мероприятия, педагоги, расписание, контакты** |
| `js/main.js` | Шапка, подвал, меню, версия для слабовидящих |

## Как заполнять

- **Педагоги, новости, мероприятия, расписание** — правьте только `js/data.js`.
- **Фото педагогов** — положите в `img/staff/` и укажите `photo: "img/staff/имя.jpg"`.
- **Фото на главном экране** — положите файл `img/hero.jpg` (подхватится автоматически).
- **Документы** — положите PDF в папку `docs/` и замените `href="#"` на путь к файлу.
- **Адрес** — заполните `address` в `js/data.js` (сейчас стоит заглушка).
- **Карта** — вставьте код из конструктора Яндекс.Карт в `contacts.html` (блок `map-box`).
- Пункты меню меняются в `js/main.js` (массивы `MENU` и `MAIN_NAV`).

## Просмотр

Откройте `index.html` в браузере или запустите локальный сервер:

```
python -m http.server 8022
```
